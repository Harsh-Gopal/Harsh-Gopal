# Development Guide

This project is built with Next.js (App Router), React, and Tailwind CSS v4.

## Prerequisites
- Node.js (v18+)
- npm

## Local Setup

1. **Install Dependencies**
   ```bash
   npm install
   ```

2. **Generate Static Assets**
   The animated greeting on the README is an SVG generated by a script. Generate it by running:
   ```bash
   node scripts/generate-greeting.js
   ```

3. **Start the Development Server**
   ```bash
   npm run dev
   ```
   The application will be available at `http://localhost:3000`.

## Scripts

- `npm run dev`: Starts the development server.
- `npm run build`: Creates an optimized production build.
- `npm run start`: Starts the production server (requires a prior build).
- `npm run lint`: Runs ESLint to check for code quality and typing errors.

## Routes
- `/`: Redirects to the Arcade hub.
- `/arcade`: The main game selection screen.
- `/games/tic-tac-toe`: Tic-Tac-Toe minigame.
- `/games/tetris`: Tetris minigame.
- `/games/dino`: Dino Run endless runner.
