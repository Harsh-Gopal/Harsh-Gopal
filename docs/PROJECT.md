# Harsh Gopal // GitHub Profile & Arcade

A premium, interactive developer portfolio directly integrated with a GitHub profile README.

## Purpose
To create a highly distinctive, custom developer identity that serves as both a GitHub profile and a playable interactive arcade. The goal is to move beyond generic static templates and present a memorable first impression for recruiters, peers, and collaborators.

## Concept
The project combines a minimal, futuristic terminal aesthetic with subtle East Asian typography influences. It integrates standard developer portfolio sections (About, Tech Stack, Currently Building) with a "Developer Arcade" containing fully playable mini-games (Tic-Tac-Toe, Tetris, Dino Run) using a unified visual language.

## Goals
- Provide a visually stunning GitHub README that stands out.
- Ensure cross-device playability for the mini-games.
- Maintain clean separation between game logic and UI presentation.
- Create a reusable, modular Next.js architecture.
- Ensure standard accessibility and performance best practices.

## Technology Stack
- **Framework**: Next.js (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS v4
- **Icons**: Lucide React
- **Typography**: Inter (sans), JetBrains Mono (terminal), Noto Sans SC (accents/identity)
- **Deployment**: Vercel (target)
